# QBCore Inventory Pro

QBCore Inventory Pro is a custom inventory system for FiveM servers using the QBCore framework. It features a dark transparent UI with black/charcoal inventory slots, thin red borders, and subtle blue accents. The inventory supports Arabic language (RTL), with Arabic item names and labels. It includes a responsive UI with smooth animations, a professional FiveM roleplay aesthetic, and full QBCore integration. The system supports drag and drop functionality, item durability, weight, descriptions, weapon support, metadata, a hotbar, and database persistence.

## Install

1. Download the QBCore Inventory Pro resource from the GitHub repository.
2. Extract the files into your FiveM server's `resources` directory.
3. Add `ensure ds_inventory` to your server.cfg file.

## Use

1. Start your FiveM server.
2. Connect to your server and open the inventory using the command or keybind you have set up.
3. Use the drag and drop functionality to move items between your inventory and the ground.
4. Use the action buttons to perform actions like using, giving, combining, throwing, or splitting items.
5. Manage your hotbar by dragging items into the hotbar slots.
